# Sophos-originated indicators of compromise

This repository is **Hellfire4959's fork** of [sophoslabs/IoCs](https://github.com/sophoslabs/IoCs), containing indicators associated with published Sophos research. It is a historical fork snapshot, not the official Sophos feed or an assurance of current coverage.

## Find an indicator file

- [Browse the file catalog](CATALOG.md): 103 source files, including CSV lists, YARA and text notes.
- [Open the upstream repository](https://github.com/sophoslabs/IoCs) for current upstream material and report context.
- [Original upstream README](UPSTREAM_README.md): retained with its Sophos Labs attribution and artwork.

## Read the data

Files cover different reports, campaigns and formats. Inspect each file's schema and source context before importing it. Keep observation dates and indicator types with matches; a historical indicator does not automatically describe the present owner or state of an address.

The source files, filenames and directory paths have been preserved. The catalog is a navigation aid; it does not normalize, deduplicate or reclassify the research data. Treat scripts and registry files as reference artifacts rather than material to execute as part of a list import.

## Contribute or update

Use a pull request for improvements specific to this fork. For corrections or additions to the official collection, follow the upstream project's process. Compare upstream changes before synchronizing the fork so local documentation can be retained deliberately.

Credit for the underlying research and original collection remains with Sophos and the original contributors.
